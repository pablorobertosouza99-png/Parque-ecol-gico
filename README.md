Parque Ecológico Paraiso Verde
1. Identificação 
integrante: Pablo de Souza
Modalidade: Projeto individual

2. Situação-problema
o projeto busca solucionar a dificuldade de acesso a informações sobre parques ecológicos,como trilhas, cachoeiras,atividades,horáriose comunicados.

3. objetivo
Desenvolver um sisdtema web para divulgar informações do Parque Ecológico Paraíso Verde e permitir o gerenciamento administrativo dos conteúdos.

4. Descrição do MVP
o MVP(Produto Minimo Viável) contempla:
.Página inicial com informações do parque
.Divulgação de trilhas, cachoeiras e atividades.
.Área de administração.
.API para consulta e atualização de conteúdos.
.Gerenciamento de comunicados.
.Banco de dados SQLite.

5. Tecnologias utilizadas

Back-end:

7. Como executar localmente

back-end
1. Instale o node.js
2. Abra o terminal na pasta do back-end.
3. Execute:
npm install
4. Configure o arquivo .env com as variáveis necessárias.
5. Inicie o servidor:
npm start
6. Acesse o endereço:
http://localhost:3000/api/health

Front-end
Abra o arquivo index.htmal utilizando a extensão Live Server no visual studio code.

8. Documentação 
A pasta docs/ reúne os documentos de escopo, requisitos e protótipos das telas.

9. Versionamento
O projeto será versionado utilizando GIt e hospedado no GITHUB, com histórico de alterações e documentação do desenvolvimento.

10. Considerações finais 
O Parque Ecológico Paraíso Verde propõe uma solução digital para facilitar a divulgaçao de informações do parque e o gerenciamento de seus conteúdos.
